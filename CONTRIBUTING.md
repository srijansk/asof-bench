# Contributing to asof-bench

asof-bench v0.1 is a pre-registered benchmark: [PREREGISTRATION.md](PREREGISTRATION.md) fixes its questions, gold, scoring and entrants, and every change to a registered file after the freeze is recorded in [DEVIATIONS.md](DEVIATIONS.md) with its date and reason.

To report a suspected wrong gold answer, a rebuild that does not match the registered data, a broken link or anything else, follow [Reporting problems](README.md#reporting-problems) in the README. For a suspected gold error, the [issue template](.github/ISSUE_TEMPLATE/gold-error.md) asks for the item id, the answer you expect, and the repository, path and commit that show it.

If you maintain one of the systems that v0.1 enters, you are invited to review its adapter and configuration before any scored run: open an issue, as the README's [Entrants and outside entries](README.md#entrants-and-outside-entries) section describes.

To run the tests, see [Development](README.md#development) in the README.
